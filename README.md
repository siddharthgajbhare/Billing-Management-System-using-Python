# 🛒 Billing Management System

A desktop-based **Billing Management System** developed using **Python** and **Tkinter**. The application enables users to generate supermarket bills by selecting products, calculating taxes automatically, and displaying a detailed invoice in an easy-to-use graphical interface.

---

## 📖 Overview

The Billing Management System simplifies the billing process for grocery stores and supermarkets. Users can enter customer details, select products from different categories, calculate the total bill with taxes, and generate a printable bill.

---

## ✨ Features

- 🧾 Generate customer bills
- 👤 Customer information management
- 🥫 Snacks category
- 🛍 Grocery category
- 🧴 Beauty & Hygiene category
- 💰 Automatic tax calculation
- 🧮 Total bill calculation
- 📄 Invoice generation
- 🔄 Clear all fields
- ❌ Exit application
